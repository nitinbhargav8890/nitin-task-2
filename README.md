# CSS Task 1

Plain HTML + CSS project (no Bootstrap) that recreates the given expected output.

## Files
- `index.html` – page structure (headings, paragraphs, lists)
- `style.css` – all styling (linked from index.html)
- `README.md` – this file

## What is covered
- Body background color
- 3 headings with class `head` (dark blue text)
- 2nd heading with id `bglime` (lime background, "head" in red)
- 3 paragraphs styled only with the `p` selector (white text)
- 2nd paragraph with id `para` (green text)
- "paragraph" word in black with a bigger font size
- 2 lists (ul, ol) where the "here" links and list items are styled without inline CSS, classes or ids (using `li:first-child`, `li:nth-child()` etc.)

## How to run
Open `index.html` in any browser.
